### ⚡ Core Modules & Features
* **Downloader & Torrent:** Multi-threaded chunking engine with integrated BitTorrent and magnet link handling.
* **Omni Archive:** High-compression file packaging engine with military-grade AES-256 and standard ZIP archive support.
* **Music Studio:** Studio-grade DSP equalizer, dynamic circular audio visualizer, and LRC lyrics synchronization.
* **Cinema Player:** 4K hardware-accelerated LibVLC engine with dual-audio dubbing and subtitle matching.
* **Media & GIF Viewer:** High-speed image preview and animated GIF player with smooth zoom gestures.
* **PDF Studio:** Document viewing powered by Google PDFium with draggable sticky notes and annotations.
* **Windows Doctor:** Real-time hardware telemetry (CPU, GPU, RAM, Storage) and memory cache optimizer.
* **Deep Uninstaller:** Application scanning with administrative silent uninstaller and registry residue cleanup.
